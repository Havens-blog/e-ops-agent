# UI Design: Haven 运维 Agent

## Design System

采用 **Shadcn** 风格（zinc 中性色、功能性极简、flat surface + 1px border、light 默认 / dark 可切）。

### Color Palette (Light)

| Role | Variable | Value |
|------|----------|-------|
| Background | --background | #ffffff |
| Foreground | --foreground | #09090b |
| Card | --card | #ffffff |
| Primary | --primary | #18181b |
| Primary Foreground | --primary-foreground | #fafafa |
| Secondary / Muted | --secondary / --muted | #f4f4f5 |
| Muted Foreground | --muted-foreground | #71717a |
| Destructive | --destructive | #b91c1c |
| Border / Input | --border / --input | #e4e4e7 |
| Ring | --ring | #18181b |

风险级别徽标（唯一规范）：统一按「浅底深字」token 配对，全站仅此一种徽标配色——高危徽标底 `#fee2e2` + 字 `#991b1b`；低危徽标底 `#fef3c7`（amber-100）+ 字 `#92400e`（amber-800），对比度 ≈6.3:1；正常/只读徽标底 `#dcfce7` + 字 `#166534`。原始饱和色 `#dc2626`（red-600）、`#b45309`（amber-700）、`#16a34a`（green-600）**不作徽标填充**（既不作底色也不作徽标文字色），仅降级为装饰性边框/图形色（如高危卡片左侧 4px 色条、状态图标）；amber-500 `#f59e0b` 对比度不足（≈2.2:1），同样仅允许作装饰性边框/图形，不得作白底文字色。destructive 填充色采用 red-700 `#b91c1c`（白字对比度 ≈6.5:1，满足 AA 4.5:1），hover 加深至 `#991b1b`；`#ef4444` 不再作文字承载填充色，仅允许用于装饰性边框/图形。「红 tinted 提示条」统一为浅底深字 token：底 `#fee2e2` + 字 `#991b1b`（错误文案），不再使用无 token 的裸红色。

「降级」标签 token（全站统一，五处复用见组件规范 Badge 段）：amber「浅底深字」配对——light 底 `#fffbeb`（amber-50）+ 字 `#78350f`（amber-900），对比度 ≈10.9:1；dark 底 `#422006`（amber-950）+ 字 `#fde68a`（amber-300）。与低危徽标（`#fef3c7`/`#92400e`）同属 amber 族但色值错开，避免两种语义同色；造型与风险徽标一致（rounded-full pill），语义独立。

「并发冲突提示」token（冲突 Dialog 提示条专用）：蓝「浅底深字」配对——light 底 `#dbeafe`（blue-100）+ 字 `#1e40af`（blue-800），对比度 ≈7.6:1；dark 底 `#172554`（blue-950）+ 字 `#93c5fd`（blue-300）。冲突语义为第三种警示色调，**独立成蓝、整体移出 amber 族**，不得复用低危徽标（`#fef3c7`/`#92400e`）或降级标签（`#fffbeb`/`#78350f`）的任何一端色值——同一 amber 族内出现第三种语义即违反「避免两种语义同色」原则。dark 下同理：`#172554`/`#93c5fd` 为冲突提示专用，排查中徽标 dark 字色错开为 `#bfdbfe`（见 Badge 段）。

### Color Palette (Dark)

与 Light 同名变量整体切换（`html.dark` 下覆盖同名 CSS 变量），支撑顶栏「明暗切换 | 切换 CSS 变量 | 全站换肤」交互：

| Role | Variable | Value |
|------|----------|-------|
| Background | --background | #09090b |
| Foreground | --foreground | #fafafa |
| Card | --card | #18181b |
| Primary | --primary | #fafafa |
| Primary Foreground | --primary-foreground | #18181b |
| Secondary / Muted | --secondary / --muted | #27272a |
| Muted Foreground | --muted-foreground | #a1a1aa |
| Destructive | --destructive | #b91c1c |
| Border / Input | --border / --input | #27272a |
| Ring | --ring | #d4d4d8 |

dark 模式语义色按「深底浅字」等价翻转（对比度均 ≥ 4.5:1）：高危徽标底 `#450a0a` + 字 `#fecaca`、低危徽标底 `#451a03` + 字 `#fcd34d`、正常徽标底 `#052e16` + 字 `#bbf7d0`；红 tinted 提示条 dark 底 `#450a0a` + 字 `#fecaca`。destructive 填充 dark 下保持 `#b91c1c`（白字 ≈6.5:1，与主题无关）；amber-500 仅装饰边框的规则在 dark 下同样生效。

### 可访问性（Accessibility）

- **对比度**：正文、徽标文字、placeholder 均满足 WCAG AA ≥ 4.5:1（见色板语义色「浅底深字」规范）；`--muted-foreground #71717a` 仅用于 ≥13px 辅助文字（白底对比度 ≈4.8:1）。
- **表单标签**：所有输入（对话输入框、时间范围、服务名、检索条件）均有可见 `<label>` 或 `aria-label`，筛选条不允许仅 placeholder 承载语义。
- **键盘导航**：全站可 Tab 到达、可见 focus ring（2px `--ring`）；表格行 checkbox 用 Space 切换；批量操作按钮 Tab 顺序跟随机选行；结论行、折叠调用链、示例 chip 均实现为 `<button>`，Enter/Space 触发；Dialog 打开时 focus 移入并 trap，Esc 关闭、关闭后 focus 归还触发元素。**悬停类内容均有键盘等价路径**：长文本单元格全文、降级原因与能力边界等 tooltip 一律为「悬停 + 聚焦」双触发（元素 `tabindex=0`，focus / Enter / Space 打开，Esc / 失焦关闭），不依赖纯 mouse hover；触屏以点击切换。
- **动态播报（aria-live）**：对话「排查中」状态容器 `aria-live="polite"`（播报步骤文字变化）；skeleton 加载区设 `aria-busy="true"`；错误提示与部分失败 toast 用 `role="alert"`；**成功类轻提示全站统一用 `role="status"`**（polite 播报一次，与错误的 alert 语义区分），覆盖「已标记已查看」轻提示、批量标记全部成功 toast、重试全部成功 toast；截断徽标、并发冲突提示均在 aria-live 区域内播报；纯视觉 spinner 另配文本替代。

| Role | Font | Weight | Size |
|------|------|--------|------|
| H1 | Inter | 700 | 28px |
| H2 | Inter | 600 | 20px |
| Body | Inter | 400 | 14px |
| Small / Muted | Inter | 400/500 | 13px |

Font stack: `-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, 'PingFang SC', 'Microsoft YaHei', sans-serif`

### 组件规范

- **Button**：primary 底 `--primary` 白字；secondary 底 `--secondary`；outline 透明+边框；ghost 透明 hover 灰底；destructive 底 `--destructive #b91c1c`（red-700）白字，对比度 ≈6.5:1 满足 AA（见色板说明）。rounded-md(6px)，h-9，px-4，text-sm，150ms opacity 过渡，无阴影。
- **Card**：白底、rounded-lg(8px)、1px `--border`、p-6、无阴影。
- **Input**：透明底、1px `--input`、rounded-md、h-9、focus ring 2px。
- **Badge**：rounded-full、px-2.5 py-0.5、text-xs；风险徽标见色板语义。**降级标签变体**：amber「浅底深字」token 底 `#fffbeb` + 字 `#78350f`（dark：底 `#422006` + 字 `#fde68a`），同 pill 造型，全站五处复用统一样式——风险中心「降级」列、诊断详情头部 badge、历史会话「降级」列、会话视图顶部 badge、对话页「降级模式」badge；不得与风险级别徽标混用配色。**其余徽标变体（全站仅以下 4 种，均沿用 pill 造型与 text-xs 字号，仅以 token 配对区分语义）**：
  - **截断徽标**：中性灰「浅底深字」——light 底 `#f4f4f5`（zinc-100）+ 字 `#3f3f46`（zinc-700，对比度 ≈8.2:1）；dark 底 `#27272a` + 字 `#d4d4d8`。用于「结果已截断，共 N 条匹配」（三个表面：对话报告 Card 顶部、诊断详情、会话视图报告 Card）。
  - **排查中状态徽标**：信息蓝「浅底深字」——light 底 `#dbeafe`（blue-100）+ 字 `#1d4ed8`（blue-700，对比度 ≈5.9:1）；dark 底 `#172554` + 字 `#bfdbfe`（blue-200，对比度 ≈10.2:1）。用于会话「排查中…」固定状态徽标；与冲突提示 token 同族但两端错开——light 侧字色错开（`#1d4ed8` vs `#1e40af`），dark 侧同样字色错开（`#bfdbfe` vs `#93c5fd`），避免进行中状态与并发警示两种语义在任一模式下同色。
  - **超能力意图 badge**：紫「浅底深字」——light 底 `#ede9fe`（violet-100）+ 字 `#5b21b6`（violet-800，对比度 ≈7.0:1）；dark 底 `#2e1065` + 字 `#c4b5fd`。用于「引导式回应」Card 顶部。
  - **降级模式 badge**：直接复用「降级」标签 token（同色同形，见上），不另设配色。
- **Table**：header 底 `--muted`、行 hover `--muted/50`、仅行间 border-b。
- **Dialog**：遮罩黑 80% + backdrop-blur，内容白底 rounded-lg max-w-lg。

### 布局

Top navigation bar（`/opsagent/chat` 对话排障、`/opsagent/risk-center` 风险中心）在**全部 4 个页面**渲染，含二级页（诊断详情、历史回溯），Primary Navigation shared across pages；二级页在顶栏下方追加 breadcrumb，返回目标按进入来源感知（见 Component 3/4）。无强制 max-width，fluid；间距 4px base（p-6=24px、gap-4=16px）。

### 响应式（Responsive）

- **断点与列折叠（风险中心 8 列表格）**：≥1280px 全部 8 列展示；768–1279px 隐藏「风险分」「降级」两列（风险分并入级别徽标 tooltip、降级标签内联渲染在服务名下方小字，点击标签展开/收起降级原因与能力边界），其余 6 列保留；<768px 表格降级为卡片列表（每条目一卡：checkbox + 服务名 + 级别徽标 + 状态 + 时间 + 操作，降级原因同样以点击展开的小字呈现），批量操作条吸顶，筛选条折叠为「筛选」按钮弹出 Dialog。历史会话表格（6 列）同策略：<768px 折叠为卡片。
- **长文本溢出**：服务名、根因结论、处置建议等单元格 max-width + `text-overflow: ellipsis`，悬停**或键盘聚焦**触发 tooltip 展示全文（元素设 `tabindex=0`，focus / Enter / Space 打开，Esc / 失焦关闭，见「可访问性」）；触屏设备（<768px 卡片视图）以点击展开/收起替代悬停；卡片内长文本换行（`break-words`）。
- **对话页输入区 fixed 语义**：输入区 `position: fixed` **相对 viewport**（`left:0; right:0; bottom:0`），不在页面 flex 容器文档流内；对话流滚动容器预留 `padding-bottom = 输入区实际高度`（含字数/模式小字行），避免末条消息被遮挡。上方 wireframe 为逻辑分区示意，非文档流布局。

## Component 1: 对话面板（/opsagent/chat）

### Placement
- **Mode**: new-page
- **Target**: /opsagent/chat
- **Position**: 整页：顶部共享导航 + 中部对话流 + 底部输入区

### Layout Structure

```
┌──────────────────────────────────────────────┐
│ [对话排障] [风险中心]      [历史诊断] (导航)   │
├──────────────────────────────────────────────┤
│  对话流（滚动区，space-y-4）                   │
│   ┌ 用户气泡（右对齐，secondary 底）────────┐  │
│   ┌ 系统诊断卡片（左对齐，Card）───────────┐  │
│   │  根因结论 / 处置建议 / 数据源引用⬇     │  │
│   │  状态徽标：降级/引导式回应/错误        │  │
│   │  [截断徽标（如有）：结果已截断·共N条]  │  │
│   │  [查看详情 →]（跳诊断详情页）          │  │
│   └───────────────────────────────────────┘  │
├──────────────────────────────────────────────┤
│ [文本输入框........................] [发送]   │
│ 小字提示：x/500 · 当前模式（正常/降级）        │
└──────────────────────────────────────────────┘
```

- 顶栏：品牌名 + 两个一级导航项 + 右侧「历史诊断」ghost 入口按钮（跳转 /opsagent/history，即 PRD UF-1「历史诊断」入口）+ 明暗切换。
- 对话流：flex-column 滚动容器；用户消息右对齐 badge 灰底，系统回复左对齐 Card。
- 诊断报告 Card 右下角固定「查看详情 →」outline 小按钮：点击跳转 /opsagent/diagnosis/:id?from=chat（携带来源），即 PRD UF-1 结论跳转，使诊断详情面包屑来源「对话排障」可达。
- 输入区：fixed 底部（相对 viewport，见「布局 > 响应式」说明），Input + 「发送」Button；下方 muted 小字提示字数与模式。空输入时「发送」Button 置为 disabled（`disabled` 属性 + `aria-disabled`，视觉 opacity-50 + cursor-not-allowed），输入非空方可点击（PRD：空输入不可发送）；输入达到 500 字符上限时同样阻止发送并提示精简（见 Interactions「输入达到 500 字符上限」行）。

### States

| State | Visual | Behavior |
|-------|--------|----------|
| 空 | 居中引导语 + 3 个示例问题 chip | 点击 chip 填入输入框 |
| 排查中 | 系统气泡内 spinner + 当前步骤文字（气泡旁固定状态徽标「排查中…」），步骤按固定顺序枚举：① 意图识别中 → ② 查询日志/资产/告警中 → ③ 诊断计算中 → ④ 生成报告中 | 步骤文字随编排层事件流实时切换（aria-live 播报变更）；④「生成报告中」即 PRD 第二阶段，报告 Card 以 skeleton 占位出现，渲染完成后气泡替换为最终报告（完成/降级/引导式回应/错误态之一） |
| 完成 | 诊断报告 Card（结论/建议/引用） | 点结论行展开数据源引用 |
| 引导式回应 | Card 顶部「超能力意图」badge + 明示边界 + 渠道提示 | 无调用动作，仅引导 |
| 降级 | Card 顶部「降级模式」badge + 预置查询入口 chips | 提示能力边界 |
| 结果截断 | 报告卡片顶部截断徽标：「结果已截断，共 N 条匹配，请缩小时间窗或服务范围」 | logquery 结果超 1000 条 / 10 MB，超出部分不静默丢弃 |
| 错误 | 红 tinted 提示条 + 重试按钮 | 底座超时且无可回退 |

**异步阶段流转**（PRD「流式/异步展示报告生成状态：排查中 → 生成报告」）：发送后系统气泡按 ① 意图识别中 → ② 查询日志/资产/告警中 → ③ 诊断计算中 → ④ 生成报告中 顺序流转，每步由编排层事件推送更新文字；进入 ④ 后报告区先渲染 skeleton 占位，内容就绪后以最终报告 Card 替换气泡。任一步骤失败且无可回退则直接进入「错误」态；降级路径在 ② 之前即被识别，跳过 ③④ 直接展示「降级」Card；超能力意图在 ① 结束后直接展示「引导式回应」Card。

### Interactions

| Trigger | Action | Feedback |
|---------|--------|----------|
| 输入为空（含仅空白字符） | 「发送」Button 保持 disabled，点击无效 | 按钮 opacity-50 + cursor-not-allowed（PRD：空输入不可发送） |
| 输入达到 500 字符上限 | 阻止继续输入：`maxLength=500` 硬截断，第 501 个字符不再上屏；删减至 ≤500 后自动恢复（PRD：超长提示精简） | 计数红显「500/500 · 已达上限，请精简描述」（红 tinted 文字 `#991b1b`，`role="status"` 播报一次）；「发送」保持 disabled 直至删减到限内 |
| 发送 | 提交问题，进入排查中 | 消息上屏 + spinner |
| 点结论行 | 展开数据源引用 | 内联展开 |
| 点报告 Card「查看详情」 | 跳转 /opsagent/diagnosis/:id（携带 ?from=chat） | 页面跳转 |
| 点示例 chip | 填入输入框 | 文本回填 |
| 点「历史诊断」入口 | 跳转 /opsagent/history | 页面跳转 |
| 明暗切换 | 切换 CSS 变量 | 全站换肤 |

### Data Binding

| UI Element | Data Field | Source |
|------------|-----------|--------|
| 会话消息列表 | messages[] | 编排层 |
| 空态示例问题 chip（3 个） | suggestedQuestions[]（示例问题文案数组） | 编排层（可配置；未配置时渲染内置默认三条） |
| 诊断报告 Card | 根因/建议/引用数组 | 编排层 |
| 报告状态 badge | 报告状态枚举 | 编排层 |
| 降级标识 | 降级标识 + 原因 | 编排层 |
| 截断徽标 | truncated（布尔）+ totalMatched（总匹配数 N） | 编排层（logquery 元信息） |
| 报告 Card「查看详情」按钮 | diagnosisId（当前诊断 id，拼入 /opsagent/diagnosis/:id?from=chat） | 编排层 |
| 「历史诊断」入口按钮 | 无数据字段（静态导航控件，目标 /opsagent/history?from=chat） | — |

## Component 2: 风险中心列表（/opsagent/risk-center）

### Placement
- **Mode**: new-page
- **Target**: /opsagent/risk-center
- **Position**: 整页：顶导航 + 筛选器 + 列表

### Layout Structure

```
┌────────────────────────────────────────────────┐
│ [对话排障] [风险中心]                 (导航)    │
├────────────────────────────────────────────────┤
│ 筛选条：租户(锁定)|时间范围|服务名 [筛选][历史诊断] │
├────────────────────────────────────────────────┤
│ [☑ 全选] [批量标记已查看] [批量标记已处理]      │
│ ┌──诊断条目表格──────────────────────────────────────┐ │
│ │ ☑|服务名   |级别徽标|风险分|时间 |状态  |降级 |操作   │ │
│ │ ☑|order-svc|高危    |85    |09:45|待查看|—    |查看详情 ⋯│ │
│ │ ☐|cdn-edge |正常    |12    |09:44|已查看|降级 |查看详情 ⋯│ │
│ │ ☐|cache-svc|低危    |34    |09:40|已处理|—    |查看详情 ⋯│ │
│ └───────────────────────────────────────────────────┘ │
│ 分页：< 1 2 3 > · 共 N 条                      │
└────────────────────────────────────────────────┘
```

- 筛选条：租户选择器锁定为当前登录租户并强制注入；时间范围、服务名输入。筛选条右侧固定「历史诊断」outline 按钮（PRD：历史诊断回溯可从「风险中心检索」进入），点击跳转 /opsagent/history?from=risk-center，使历史诊断回溯的第二 PRD 入口可达。
- 批量操作条：全选 checkbox + 两个批量标记按钮（超过 50 条禁用并提示）。

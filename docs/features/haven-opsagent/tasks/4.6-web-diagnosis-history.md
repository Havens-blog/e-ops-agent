# 4.6: web 诊断详情 + 历史回溯 handler

## Description
实现 `GET /opsagent/diagnosis/:id`（诊断详情，含 conclusions/citations/trace/disposition；带 `?riskEntryId=` 时惰性触发 `pending_view → viewed` 窄状态迁移）+ `GET /opsagent/history`（按租户/时间/服务名检索会话，≤24h，返回 SessionSummary / 详情含编排调用链）。

## Reference Files
- docs/features/haven-opsagent/design/api-handbook.md — §6 诊断详情、§7 历史检索
- docs/features/haven-opsagent/design/tech-design.md — PRD Coverage Map（自动已读触发点）、Data Models（sessions/diagnoses）
- docs/features/haven-opsagent/design/page-map.md — 诊断详情 / 历史回溯页数据源

## Acceptance Criteria

- [ ] 诊断详情返回完整报告（根因/结论/引用/编排调用链/处置预案）
- [ ] `GET /diagnosis/:id?riskEntryId=` 惰性触发 pending_view→viewed（CAS，幂等，无参访问零副作用）
- [ ] 历史检索 1 分钟内、按租户/时间/服务名检索、跨租户 404（SC-5/SC-6）
- [ ] 时间窗上限 24h，超出提示缩小范围
- [ ] 集成测试覆盖详情/自动已读/检索（≥80%）

## User Stories
- Story 2：诊断详情查看自动已读
- Story 3：历史回溯 1 分钟检索、结论回指数据源

## Hard Rules
- 跨租户访问 404，不泄露存在性
- 自动已读迁移为窄状态 CAS，不覆盖并发 done 标记

## Implementation Notes
- 历史检索时间窗默认 ≤24h（可配）
- 详情含编排调用链（Diagnosis.trace）

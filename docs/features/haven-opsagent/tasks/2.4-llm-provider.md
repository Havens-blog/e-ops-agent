# 2.4: LLM Provider 抽象 + GuardedLLM 降级封装

## Description
实现 `internal/llm`：`LLMProvider` 接口（qwen 为主 / deepseek / openai 可配）+ `GuardedLLM` 降级封装：`IsAvailable` 判定谓词（单次超时 >12s、连续 2 次失败、未配置 Disabled），`CompleteGuarded` 返回 `(text, available)`，不可用时返回空串不阻塞。

- [ ] `LLMProvider` 接口 + qwen/deepseek/openai 三个 provider 实现（apiKey 自 env 注入，不入库不入码）

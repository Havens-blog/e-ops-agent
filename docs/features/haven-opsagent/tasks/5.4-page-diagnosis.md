# 5.4: 诊断详情页（RootCauseCard/EvidenceList/TraceView/DispositionList）

## Description
实现 `/opsagent/diagnosis/:id` 页面：根因结论 RootCauseCard（主视觉根因 + 置信度）、证据清单 EvidenceList（六类证据）、编排调用链 TraceView（各步骤调用底座与耗时）、处置预案 DispositionList（只读预案 + 风险档徽标）。

## Acceptance Criteria

- [ ] 根因结论 + 置信度主视觉展示
- [ ] 证据清单六类（时间相关/错误频率/指标异常/拓扑距离/变更关联/Trace）可回指数据源引用
- [ ] 编排调用链逐步骤（agent/action/来源/耗时）展示
- [ ] 处置预案只读展示 + 风险档徽标（read/low/high）
- [ ] 打开详情（带 riskEntryId）触发自动已读（pending_view→viewed），页面状态随之刷新
- [ ] 组件 TS 类型与 Diagnosis DTO 一致（编译通过）

## User Stories
- Story 2：查看诊断内容自动流转已查看
- Story 3：结论回指数据源、二次核实可信度

## Hard Rules
- 处置预案只读（P1 无执行后端），不渲染执行控件

## Implementation Notes
- 自动已读：详情 GET 请求携带 riskEntryId 由后端惰性 CAS
- TraceView 展示 DegradeLevel（降级级别）

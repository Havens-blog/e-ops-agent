# 5.3: 风险中心页（StatCards/FilterBar/RiskTable/StatusMark/HighRiskTag）

## Description
实现 `/opsagent/risk-center` 页面：统计卡 StatCards（pendingView/todayNew/highRisk）、筛选栏 FilterBar（租户/时间/服务名/状态/severity）、待办表 RiskTable（条目列表 + 单条/批量标记）、状态标记 StatusMark（已查看/已处理 + 并发冲突 409 刷新）、高危标记 HighRiskTag（纯展示不渲染确认控件）。

- docs/features/haven-opsagent/design/page-map.md — 风险中心页 Page Sections
- docs/features/haven-opsagent/ui/prototype/risk-center.html — 交互原型（筛选/批量/冲突对话框）

- docs/features/haven-opsagent/design/tech-design.md — Data Models（risk_entries/RiskEntry/severity 徽标）

## Acceptance Criteria

- [ ] 列表按租户/时间/服务名/状态/severity 筛选 + 分页
- [ ] 统计卡展示 stats 聚合
- [ ] 单条/批量标记已查看/已处理；批量冲突项回显失败清单 + 重试入口
- [ ] 并发冲突 409 → 提示「已被其他值班更新」+ 刷新最新状态
- [ ] 高危条目（riskLevel=high）仅展示「待人工确认」标记，不渲染确认/执行控件
- [ ] 组件 TS 类型与 api-handbook RiskEntry 一致（编译通过）

## User Stories
- Story 1：风险中心筛选、单条/批量标记、部分失败重试、并发冲突、高危仅展示

## Hard Rules
- 高危条目不渲染任何确认/执行控件
- 批量逐条 CAS，冲突不静默覆盖

## Implementation Notes
- severity 徽标 P0/P1/P2/P3 + risk 档徽标（read/low/high）
- 自动已读（待查看→已查看）由详情页触发走 GET /diagnosis/:id?riskEntryId=

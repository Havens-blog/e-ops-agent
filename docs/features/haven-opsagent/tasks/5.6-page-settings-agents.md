# 5.6: 系统配置 + Agent 管理页

## Description
实现 `/opsagent/settings`（4 tab：数据源配置 DatasourceTab、LLM 模型 LLMTab、通知渠道 NotifyTab、安全与租户 SecurityTab + 预置查询 PresetTab）+ `/opsagent/agents`（4 逻辑 Agent 状态卡片、任务队列、负载历史、LLM 预算用量）。

## Reference Files
- docs/features/haven-opsagent/design/page-map.md — 系统配置 / Agent 管理页 Page Sections
- docs/features/haven-opsagent/ui/prototype/settings.html — 配置原型（4 tab + 数据源/提供商/渠道/白名单）

## Acceptance Criteria

- [ ] 数据源配置 tab：5 数据源连接状态 + 展开字段
- [ ] LLM tab：3 提供商选择（默认 + 掩码 key）+ API 配置
- [ ] 通知渠道 tab：4 渠道开关
- [ ] 安全与租户 tab：租户注入开关 + 风险白名单表（只读/低危/高危三档）+ 底座契约冻结状态
- [ ] 预置查询 tab（presetQueries 目录）可配置
- [ ] Agent 管理页展示 4 逻辑 Agent 状态/负载 + 队列 + LLM 预算

## User Stories
- 系统配置页（数据源/LLM/通知/白名单）支撑 P1 运行
- Agent 管理页（多 Agent 观测）

## Hard Rules
- API Key 只写不读（GET 显示掩码）
- 高危档不允许入白名单

## Implementation Notes
- settings 六类 scope：datasource/llm/notify/risk_whitelist/preset_queries/guided_templates
- Agent 管理页数据来自 GET /opsagent/agents/observability
- 移除陈旧「租户注入开关」控件——tenant 强制注入为硬约束，不可配置关闭

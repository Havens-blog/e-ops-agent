# 3.1: IntentClassifier 意图识别与能力路由

## Description
实现 `internal/orchestrator/intent`：`Classify` 将自然语言输入分类到 `diagnose / resource / out_of_scope`，抽取 `DiagnoseParams`（服务名/时间窗/指标），返回 `IntentResult`（含置信度/备选意图/是否需要澄清）；`Correct` 支持 target+params XOR message 两条纠正路径并记录 `correction_log`。LLM 不可用时走模板/正则意图匹配（L1 降级内置）。

- docs/features/haven-opsagent/design/tech-design.md — Interface 1 IntentClassifier、LLM 三级降级设计（L1 模板匹配）、澄清与纠正落点
- docs/features/haven-opsagent/design/api-handbook.md — §1 chat、§2 correct（type=clarify + candidates）
- docs/features/haven-opsagent/prd/prd-user-stories.md — Story 2（超能力引导/澄清纠正 AC）

## Acceptance Criteria

- [ ] 意图分类三态正确（diagnose/resource/out_of_scope），out_of_scope 不调用底座、返回引导式回应
- [ ] `DiagnoseParams` 抽取：服务名/时间窗/指标；抽取不出服务名 → 触发 L2 澄清
- [ ] LLM 不可用时回退模板/正则匹配（不依赖 LLM）
- [ ] `NeedsClarify=true` 时返回 candidates 供一键纠正；`Correct` 重路由并保留误分类 + 纠正记录
- [ ] `Correct` 支持 target+params 与 message 两条路径（XOR）
- [ ] 单元测试覆盖分类/澄清/纠正/超能力引导（≥80% 覆盖）

## User Stories
- Story 2：对话框意图识别、超能力意图引导、低置信度澄清与纠正

## Hard Rules
- 超能力意图不调用底座、不猜测、不真实转发
- 引导式回应话术来自 settings.guided_templates（Flow C）

## Implementation Notes
- L1 降级逻辑内置于 Classify；L2/L3 由 3.3 DegradationController 决策

### Key Decisions
- 高危判定用 severity∈{P0,P1}：RiskEntry 域类型无 riskLevel 字段，tech-design RiskStats.highRisk 同口径（severity P0|P1）；AC「riskLevel=high」为宽泛措辞，落地按 severity。HighRiskTag 纯展示「待人工确认」，P1 无执行后端故全程不渲染确认/执行控件（Hard Rule）
- 状态标记动作派生 markableActions：pending_view→viewed/done、viewed→done、done→无；待查看→已查看由详情页 GET /diagnosis/:id?riskEntryId= 自动流转（5.4 范围），风险中心不主动标 viewed
- CAS 冲突 409：opsagentAxios 仅拦截 401 跳登录、不拦截 4xx，unwrapOpsagent 对非 2xx 信封抛 OpsagentRequestError(code=ERR_CONFLICT, data=最新 RiskEntry)→ 页面提示「已被其他值班更新」并 reload 最新状态
- 批量逐条 CAS（不整批事务）：batch 请求由 selected 条目 id+version 组装；失败按 reasonCode 归并 conflict/not_found（batchOutcome 纯函数），部分失败回显 ElMessageBox 失败清单，重试 = 刷新后重勾选
- el-* 组件经 unplugin-vue-components 构建期解析，但 vitest 环境不含 Components resolver：可测组件（StatusMark）改用原生 button 保持 happy-dom 可挂载；el-table/el-input/el-date-picker 仅运行时经真实构建解析，逻辑经 logic.ts 纯函数单测覆盖
- 时间窗用 el-date-picker datetimerange + value-format YYYY-MM-DDTHH:mm:ssZ（dayjs Z=时区偏移）产出 RFC3339；空则不参与过滤

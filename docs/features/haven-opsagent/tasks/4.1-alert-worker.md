# 4.1: 告警 worker（指纹去重/并发/队列/LLM 预算）

## Description
实现 `internal/worker` 告警异步排查：指纹聚合去重（Redis SET NX + TTL 10min，窗口内同指纹仅一次排查）、并发上限 5（semaphore）、等待队列 100（有界 channel）、LLM 滚动 1h 预算（Redis INCR）。队列溢出丢弃低级别告警（保留原文 + 去重结论，高危不丢）；预算耗尽自动降级纯规则结论。

## Acceptance Criteria

- [ ] 同指纹 10min 窗口内仅触发一次排查，后续归并 `$inc count` + `merged`
- [ ] 并发上限 5、排队队列 100；队列满溢出丢弃低级别（保留原文）+ 高危不丢
- [ ] LLM 滚动 1h 预算耗尽 → 降级纯规则结论，排查/落库/推送不中断
- [ ] 溢出丢弃写 alerts 文档（`overflow_dropped`），webhook 返回 202 + `data.dropped=true`
- [ ] 高危告警不因队列满被丢弃
- [ ] 单元测试覆盖去重/并发/队列溢出/预算耗尽（≥80%）

## User Stories
- Story 1：告警指纹聚合去重、并发上限排队、队列溢出、LLM 预算降级

## Hard Rules
- P1 单实例部署（队列/并发为进程局部资源，多实例语义失效）
- 高危告警永不丢弃

## Implementation Notes
- 指纹用 domain.Fingerprint（1.2）；Redis 仅去重/预算触发信号
- 多实例共享队列迁移列入 P2，不在 P1 承诺范围

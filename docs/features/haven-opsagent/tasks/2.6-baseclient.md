# 2.6: BaseModuleClient 底座契约客户端

## Description
实现 `internal/baseclient`：logquery 日志查询（QueryLogs）、资产查询（QueryAssets 经 MCP Tools）、eiam 令牌验证（VerifyToken）、通知发送（Notify）的统一 HTTP 封装。超时/重试/降级在客户端内闭环；响应结构校验失败返回 `ContractDriftError`（触发运行时降级 + `opsagent_contract_drift_total` 指标）。

## Reference Files
- docs/features/haven-opsagent/design/tech-design.md — Interface 2 BaseModuleClient、Error Handling（ERR_CONTRACT_DRIFT 运行时降级/告警路径）
- docs/features/haven-opsagent/design/api-handbook.md — Part B 底座契约（B1..B4 冻结后路径）
- docs/features/haven-opsagent/design/api-handbook.md — 契约 B4 通知

## Acceptance Criteria

- [ ] QueryLogs / QueryAssets / VerifyToken / Notify 四方法按契约实现（含超时 + 重试）
- [ ] 响应结构校验失败返回 `ContractDriftError`（含模块标识）
- [ ] 契约漂移递增 `opsagent_contract_drift_total{module}` 指标；10min 内同模块 ≥3 次升级健康告警
- [ ] 单步超时/失败降级为「无数据」证据（不 panic、不中断上层）
- [ ] 单元测试（httptest mock）覆盖成功/超时/结构漂移三态（≥80%）

## User Stories
- Story 1/2：编排调用日志/资产/告警底座
- Story 3：结论回指数据源（QueryLogs/QueryAssets 结果供引用）

## Hard Rules
- 超时/重试语义在客户端闭环，不向上抛裸错误
- 契约漂移运行时告警与 CI 契约测试相互独立、并行生效

## Implementation Notes
- 契约精确路径/字段来自 1.4 冻结结果
- 通知复用冻结的渠道复用方式（1.4 收口）

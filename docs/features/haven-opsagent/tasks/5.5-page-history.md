# 5.5: 历史回溯页（SearchBar/SessionList/SessionView）

## Description
实现 `/opsagent/history` 页面：检索栏 SearchBar（租户/时间/服务名，≤24h）、会话列表 SessionList（SessionSummary 摘要）、会话详情 SessionView（提问 + 编排调用链 + 报告 + 引用）。

## Reference Files
- docs/features/haven-opsagent/design/page-map.md — 历史回溯页 Page Sections + Query Parameters
- docs/features/haven-opsagent/ui/prototype/history.html — 交互原型（搜索 + 会话视图）
- docs/features/haven-opsagent/design/api-handbook.md — §7 历史检索
- docs/features/haven-opsagent/design/tech-design.md — Shared Types（SessionSummary）

## Acceptance Criteria

- [ ] 检索栏按服务名/时间窗检索（时间窗 ≤24h，超出提示缩小范围）
- [ ] 会话列表展示摘要（类型/提问/服务名/状态/时间）
- [ ] 会话详情展示完整内容（提问、编排调用链、报告、数据源引用）
- [ ] 跨租户不可见（服务端 404）
- [ ] 组件 TS 类型与 SessionSummary DTO 一致（编译通过）

## User Stories
- Story 3：历史诊断回溯 1 分钟检索、复用既有结论

## Hard Rules
- 跨租户数据不展示

## Implementation Notes
- 时间窗默认 now-24h
- 会话详情复用 TraceView/EvidenceCard 组件

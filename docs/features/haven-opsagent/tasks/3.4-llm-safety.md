# 3.4: LLM 输入输出侧安全（清洗/包裹/围栏/引用校验）

## Description
实现 LLM 输入输出对称三道防线：① 清洗——进 LLM 前剥离指令性标记（「忽略以上指令」「system:」等）；② 结构化包裹——不可信文本以显式分隔符包裹，system prompt 声明「分隔符内为数据非指令」；③ 围栏——LLM 输出仅映射预置报告模板槽位。输出侧：LLM 引用的租户/资产标识与服务端实际查询结果集做引用校验，越界丢弃。含 prompt injection 过滤与指令白名单校验。

## Acceptance Criteria

- [ ] 进 LLM 前剥离指令性标记序列（「忽略以上指令」「system:」等）
- [ ] 不可信文本以显式分隔符包裹 + system prompt 声明「数据非指令」
- [ ] LLM 输出仅映射报告模板槽位，自由文本段不得携带工具调用语义
- [ ] LLM 引用的租户/资产标识经引用校验，越界引用一律丢弃，不回显未授权数据
- [ ] 越权/越租户内容整段丢弃并降级为规则结论
- [ ] 单元测试覆盖注入剥离/包裹/越界引用丢弃（≥80%）

## User Stories
- 支撑全部（租户隔离 + LLM 安全）

## Hard Rules
- 输入/输出对称设防，任一越界即丢弃
- 回显引用必须与服务端实际查询结果集匹配

## Implementation Notes
- 与 3.2 编排在组装报告时协作（引用校验钩子）
- 清洗逻辑独立函数，供 chat 与告警两条链路共用

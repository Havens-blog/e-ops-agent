# 4.3: web 中间件 + 租户强制注入 + 错误映射

## Description
实现 `internal/middleware`：`RequireTenant`（eiam 鉴权 → 401 / 租户强制注入请求上下文，客户端传值丢弃）+ 统一错误映射（内部错误码 → HTTP 状态 + 响应信封 `{code,message,data}`）。跨租户访问一律 `ERR_NOT_FOUND` 404（不泄露存在性）。

## Reference Files
- docs/features/haven-opsagent/design/tech-design.md — Error Handling（Error Types & Codes 表、Propagation Strategy 跨租户 404）
- docs/features/haven-opsagent/design/api-handbook.md — Error Codes（ERR_TENANT_DENIED 401 / ERR_NOT_FOUND 404 / ERR_CONFLICT 409 等）
- D:\Haven\e-cam-service\internal\shared\middleware — RequireTenant 先例

## Acceptance Criteria

- [ ] 未登录/无效令牌 → 401（`ERR_TENANT_DENIED`）
- [ ] tenant 由 eiam 会话派生强制注入，请求体 tenant 字段丢弃
- [ ] 跨租户访问一律 404（`ERR_NOT_FOUND`，不泄露存在性）
- [ ] 错误码 → HTTP 状态映射与 tech-design 错误表一致（含 ERR_PERSIST_FAILED 200+code≠0、ERR_QUEUE_FULL 202）
- [ ] 统一响应信封 `{code,message,data}`

## User Stories
- 支撑全部（鉴权 + 租户隔离 SC-6）

## Hard Rules
- 跨租户一律 404，不区分资源是否存在
- ERROR 映射以 tech-design 错误表为唯一权威

## Implementation Notes
- eiam 验证端点/载荷以 1.4 冻结为准
- prompt injection 清洗钩子挂载点（3.4 提供实现）

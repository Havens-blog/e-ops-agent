# 5.2: 对话排障页（ChatPanel/ThinkingBlock/EvidenceCard/IntentCorrection）

## Description
实现 `/opsagent/chat` 页面：对话流 ChatPanel（提问 + 报告正文 + 降级/截断徽标）、思考过程 ThinkingBlock（4 步编排进度：意图识别→查询→诊断→报告）、证据卡 EvidenceCard（六类数据源引用）、意图纠正 IntentCorrection（候选意图一键纠正）。响应按 type 判别（report/preset_entries/degraded_notice/guided/clarify）。

## Acceptance Criteria

- [ ] 提问 → 报告正文展示（根因/结论/引用），降级/截断徽标正确展示
- [ ] 思考过程 4 步进度条随 trace 展示
- [ ] 证据卡展示六类数据源引用（点色区分 agent 角色）
- [ ] 降级响应 type 判别渲染（preset_entries 目录 / degraded_notice 说明 / guided 引导 / clarify 澄清）
- [ ] 澄清 candidates 一键纠正走 `/chat/:sessionId/correct`，无需重提完整问句
- [ ] 组件 TS 类型与 api-handbook DTO 一致（编译通过）

## User Stories
- Story 2：对话框自然语言排障、澄清纠正、超能力引导

## Hard Rules

- 高危项不渲染确认/执行控件

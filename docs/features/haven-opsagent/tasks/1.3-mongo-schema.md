## Acceptance Criteria

- [ ] `mongosh <dsn>/opsagent --file schema.mongo.js` 无错误执行（全部集合 + 索引创建）
- [ ] 每个集合含 tenant_id 前缀复合索引（多租户隔离硬约束）
- [ ] `settings` 唯一索引 `(scope, tenant_id)` 成立；`sessions` 服务名索引用顶层 `service_name`（非 `query.service_name`）
- [ ] `risk_entries` CAS 版本、`alerts` dedup 三态、`llm_usage` 预算约束注释齐备
- [ ] 集合字段与 er-diagram.md 实体一致（含 compensations 集合）

## Hard Rules
- 索引一律 tenant_id 前缀（跨租户隔离）
- 不改写 e-cam-service 的 `ecam` 库，只在独立 `opsagent` 库建集合

## Implementation Notes
- Haven 用 MongoDB（非 SQL），故「schema」以集合 + 索引落地，无 SQL DDL
- `sessions.query` 为自然语言原文 string，服务检索走顶层 `service_name`

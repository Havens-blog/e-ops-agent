# 3.5: notify 通知渠道发送 + 重试 + 失败率埋点

## Description
实现 `internal/notify`：经冻结的底座通知接口（钉钉/飞书/企微/邮件）发送告警提醒（摘要 + 诊断入口链接，不含跨租户明细），含重试（上限 3 次）与 `NotifyResult` 埋点（供 SC-2 推送成功率单独统计）。推送失败不影响风险中心落库。

## Reference Files
- docs/features/haven-opsagent/design/tech-design.md — Interface 2 BaseModuleClient.Notify、Shared Types（Notification/NotifyResult）
- docs/features/haven-opsagent/design/api-handbook.md — 契约 B4 通知渠道
- docs/features/haven-opsagent/prd/prd-spec.md — 告警提醒推送 + 推送失败率（SC-2 口径）

## Acceptance Criteria

- [ ] 四渠道（钉钉/飞书/企微/邮件）发送告警摘要 + 诊断入口链接
- [ ] 失败自动重试（上限 3 次），仍失败计入推送失败率埋点
- [ ] NotifyResult 记录 channel/ok/attempts/lastError/sentAt，落库 risk_entries.notified
- [ ] 通知内容不含跨租户明细（只有摘要 + 入口链接）
- [ ] 单元测试覆盖成功/重试/终失败（≥80%）

## User Stories
- Story 1：外部通知渠道推送告警提醒 + 失败率统计

## Hard Rules
- 通知失败不影响风险中心落库与展示
- 载荷不含跨租户数据

## Implementation Notes
- 渠道复用方式以 1.4 冻结结论为准（alert 接口 vs 直连 webhook）
- 推送成功率指标 `opsagent_notify_success_total{channel}`

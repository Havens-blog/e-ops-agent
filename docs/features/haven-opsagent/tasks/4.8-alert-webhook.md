# 4.8: alerts webhook handler（入站 + 幂等 + 溢出语义）

## Description
实现 `POST /opsagent/alerts` 入站 webhook（供 e-cam-service/alert 推送）：服务间密钥鉴权（env `OPSAGENT_ALERT_WEBHOOK_KEY`，双密钥滚动轮换）、tenant 校验、入队异步排查、队列满溢出返回 202 + `data.dropped=true`（低级别丢弃留档，高危不丢）。响应 `{accepted, dropped}`。

## Reference Files
- docs/features/haven-opsagent/design/api-handbook.md — §9 告警入站 webhook（字段 + 计数/溢出语义 + 密钥 Auth）
- docs/features/haven-opsagent/design/tech-design.md — Security Mitigations（webhook 密钥管理 env 注入 + 双密钥轮换）、Shared Types（AlertEvent）

## Acceptance Criteria

- [ ] 服务间密钥鉴权（env 注入），非法密钥 401
- [ ] tenant 服务端校验，与 webhook 密钥租户一致
- [ ] 告警入队异步排查 + 按指纹窗口记账
- [ ] 队列满溢出：低级别 202 + dropped=true 并留档 overflow_dropped；高危不丢
- [ ] 幂等：同指纹窗口内重复到达只触发一次排查
- [ ] 集成测试覆盖鉴权/入队/溢出/幂等（≥80%）

## User Stories
- Story 1：告警主动触发 + 风暴防护 + 溢出保留原文

## Hard Rules
- 密钥不入库不入码（env / secret manager 注入）
- 高危告警永不丢弃

## Implementation Notes
- 字段名统一 `timeframe`（与 AlertEvent json tag 一致，修复残留 `window` 不一致）
- 双密钥并存 24h 滚动轮换
